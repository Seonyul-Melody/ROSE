# 최예지 포트폴리오 — 수정 안내

## 폴더 구조
- index.html : 화면 뼈대 (입구, 문 위치, 타이틀, 프로필 창 글)
- css/style.css : 디자인 (색, 크기, 글로우, 버튼) — 0~16번 구간
- js/data.js : 내용 (제목, 영상 링크, 띠지 이미지·시간, 기획서 페이지, 챕터, 연락처 문구)
- js/main.js : 동작 (전환, 뷰어 넘기기, 영상 창 등) — 1~10번 구간
- images/ : 모든 이미지

## 자주 하는 수정
- 영상 연결: js/data.js의 video: "" 안에 유튜브 ID 또는 mp4 경로
- 띠지 이미지 바꾸기: images/scenes/의 같은 이름 파일로 덮어쓰기
- 기획서 페이지 바꾸기: images/docs/의 같은 이름 파일로 덮어쓰기
- 한 줄 소개, 경력: index.html의 "4. 프로필 창" 구간
- 색·글로우: css/style.css의 7~13번 구간

## 열기
index.html을 크롬으로 열면 돼요. 폴더 구조를 그대로 유지해야 이미지가 보여요.
깃허브에 올릴 때도 이 폴더 안의 파일을 구조 그대로 올리면 돼요.
